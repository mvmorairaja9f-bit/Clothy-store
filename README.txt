CLOTHY STORE - starter website

1. Upload index.html to a new GitHub repository.
2. In the repository, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select branch main and folder /(root), then Save.
5. Wait for GitHub Pages to publish the site. The public URL will appear in Settings > Pages.

Important:
- Product names and prices in this starter are sample listings. Replace them with products you are authorized to resell and your own prices.
- WhatsApp order link is configured for 8957888691.
- This starter sends order details to WhatsApp. It does not process online payments, guarantee COD, or automatically sync Meesho listings.
- Before accepting orders, confirm product availability, shipping, returns, and the platform/reseller terms. Set up a compliant payment gateway separately if you want online payments.
